# Aspire Talent Finder

Create a modern, premium, fully responsive multi-page website for ASPIRE MANAGEMENT CONSULTING W.L.L., using https://www.glinkmanpower.com/ as inspiration for structure and recruitment services, but with a unique design.

Company Details

Location: Doha, Qatar

Email: info@aspiregroupglobal.com

Website: aspiregroupglobal.com

Branding: Use the uploaded official Aspire logo throughout the website. Follow its navy-blue and orange identity: Navy #102F60, Orange #E96F25, White #FFFFFF, and light gray #F5F7FA. Preserve the logo's original proportions and colors.

Pages: Home, About Us, Services, Industries, Recruitment Process, For Employers, Careers, Contact Us, and Privacy Policy.

Homepage: Create an impressive hero section with the headline “Connecting Exceptional Talent with Extraordinary Opportunities,” professional corporate photography, and prominent “Request Talent” and “Explore Services” buttons. Include company introduction, recruitment services, industries served, a four-step recruitment process, employer solutions, and a careers section.

Design: Premium corporate appearance, clean typography, generous whitespace, elegant cards, subtle animations, professional imagery, sticky navbar, and a polished footer. Use navy for headings and backgrounds, orange for buttons and highlights, and white/light-gray sections for balance.

Functionality: Build working navigation, responsive mobile menus, contact forms, employer inquiry forms, and CV submission forms with validation and success/error states. Connect forms to a real backend when configured; never display fake submission confirmations. Do not invent job vacancies, phone numbers, client testimonials, statistics, addresses, or certifications.

Technical: Use React, TypeScript, and Tailwind CSS with reusable components, Lucide icons, SEO optimization, accessibility, and fast loading.

Build the actual multi-page website, not just a mockup. Ensure every page is responsive and visually consistent with the official Aspire brand. Use the uploaded logo asset directly, test all navigation and buttons, and clearly identify any backend integrations still required before launch.
